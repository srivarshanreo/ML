# Retail Analytics

This project contains separate notebooks and data for the customer segmentation and Rossmann sales analyses.

## Notebooks

- `notebooks/customer_segmentation.ipynb` reads `data/raw/customer_segmentation/marketing_campaign.csv`.
- `notebooks/rossmann_sales.ipynb` reads the CSV files under `data/raw/rossmann/`.

The optional Online Retail archive is stored under `data/raw/online_retail/` and is excluded from Git.
